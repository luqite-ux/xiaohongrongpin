# XiaoHongRongPin Website

Independent B2B inquiry website for Hangzhou Xiaohongrongpin Aluminum Industry Co., Ltd.

## Overview

- English single-language launch with data structures ready for later multilingual expansion.
- Product pages focus on solar aluminum frames, black aluminum frames, and custom aluminum profiles.
- Inquiry-first flow: no prices, no cart, and no online payment.
- Inquiry endpoint: `POST /api/inquiry`.

## Local Development

```bash
npm install
npm run dev
npm run build
```
